# HARISTON Telegram Bot

Информационный Telegram-бот сообщества HARISTON на Python, aiogram 3 и SQLite.

## Возможности первой версии
- Главное меню для участников: новости, информация о проекте, каналы, обучение, команда и связь.
- Административная панель внутри Telegram с управлением кнопками.
- Публикация новостей и рассылки пользователям.
- SQLite-хранилище пользователей и контента.

## Запуск
1. Создайте виртуальное окружение и установите зависимости: `pip install -r requirements.txt`.
2. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN` и `ADMIN_IDS`.
3. Запустите `python -m app`.

Административная панель доступна администраторам через кнопку «⚙️ Админ-панель» в главном меню или команду `/admin`.

Не добавляйте токен бота в репозиторий.
