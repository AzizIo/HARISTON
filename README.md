# HARISTON Telegram Bot

Асинхронный информационный бот сообщества HARISTON на **Python 3.10+**, **aiogram 3** и **SQLite**. Архитектура рассчитана на небольшой запуск (ориентир — 200–500 пользователей) без отдельного сервера PostgreSQL.

## Возможности

### Для участников
- Новости проекта, обучение, официальные каналы, команда и контакты.
- Раздел **HARISTON MEDIA**: фото, видео и документы.
- Индивидуальные настройки уведомлений: новости, анонсы и медиа.
- Персональная реферальная ссылка и счётчик приглашённых.
- Карточки команды с необязательными фотографиями и контактными ссылками.
- Навигация с возвратом в главное меню.

### Для администраторов
- Панель управления с проверкой Telegram ID.
- Создание, редактирование и удаление новостей с подтверждением удаления.
- Добавление каналов, уроков, участников команды и медиа.
- Рассылки по категориям с предпросмотром и явным подтверждением.
- Автоматические уведомления о новых публикациях и медиа с учётом настроек подписчиков.
- Управление проектным описанием и контактной ссылкой из админ-панели.
- Ограниченная параллельность, обработка недоступных чатов и повтор после Telegram flood limit.
- Отчёт о доставке, история рассылок и журнал административных действий.
- Расширенная статистика проекта и просмотр истории рассылок.

### Надёжность
- SQLite в режиме WAL, внешние ключи и индексы.
- Идемпотентная регистрация пользователей.
- Автоматическое добавление новых столбцов в существующую базу.
- Параметризованные SQL-запросы.
- Автоматические тесты без реального Telegram-токена и сети.

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните .env:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=123456789,987654321
DATABASE_PATH=data/hariston.db
```

Запуск: `python -m app`

Не добавляйте .env, токен или рабочую базу данных в Git.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest -q
```

Тесты используют временную SQLite-базу и не отправляют сообщения в Telegram.

Ручная резервная копия базы: `python -m app.backup`. По умолчанию файл создаётся в каталоге `backups/`; путь можно изменить через `--output-dir`.

## Эксплуатация
- Запускайте один polling-процесс на один токен.
- Храните .env и data/hariston.db вне публичного репозитория.
- Делайте резервные копии SQLite перед обновлениями и регулярно проверяйте восстановление.
- Реальную доставку, premium emoji и цветные inline-кнопки проверяйте в Telegram на тестовом боте.

## Структура
- app/handlers/ — Telegram handlers.
- app/services/ — прикладная бизнес-логика.
- app/database.py — SQLite schema, миграции и операции хранения.
- app/keyboards.py — inline-клавиатуры.
- tests/ — автоматические тесты.
